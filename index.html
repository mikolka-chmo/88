CASE-01

Кнопка виходить за межі картки

  • FrontEnd
  • QA
  • Designer
План команди
  1. QA показує ширину екрана та кроки відтворення.
  2. FrontEnd перевіряє width, padding і min-width.
  3. Designer підтверджує поведінку довгого тексту.

CASE-02

Форма не відправляється на мобільному

  • BackEnd
  • QA
  • Support
План команди
  1. Support збирає скарги користувачів і модель пристрою.
  2. QA відтворює помилку та додає bug report.
  3. BackEnd перевіряє відповідь API та валідацію даних.
